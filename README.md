# Pytest-BDD Test case sample demo

This repository contains Pytest-BDD (Behavior-Driven Development) test cases for validating longest substring without repeating character.

## Features

- Test the Longest Substring Without Repeating Characters
- Validate that the Submit button is disabled until text is entered.
- Validate test case with multiple inputs

## Prerequisites

Before running the tests, ensure you have the following installed:

- Python 3.x
- `pip` for managing dependencies
- A compatible browser (e.g., Chrome) and its WebDriver (e.g., `chromedriver`)
